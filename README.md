## 一、产品概述

### 产品定位

旅游Tips 是一款面向年轻旅行者的**轻决策 + 社交出行**工具。从"不知道去哪"到"行李已备齐"，用最短路径打通旅行前的所有决策环节——选城、找搭子、备行李，一站式完成。

### 核心价值

| 传统出行方式 | 旅游Tips |
|---|---|
| 刷 2 小时小红书越看越迷茫 | 场景筛选 + 转盘，3 秒出结果 |
| 搜索"XX周边游"结果泛滥 | GPS 定位自动推荐，按距离排序 |
| 群里问一圈没人响应 | 搭子广场随时找到同频旅伴 |
| 微信群反复确认时间地点人数 | 队伍信息标准化，一目了然 |
| 临时百度搜攻略，到了才发现少带东西 | AI 根据目的地+季节+人数自动生成行李清单 |
| 每次出行前花 2-3 小时做功课 | 关闭组队即生成，省时省心 |

**一句话概括：让每一次出发都有据可依。**

### 目标用户

| 人群 | 特征 | 核心诉求 |
|------|------|----------|
| 选择困难症患者 | 想旅行但不知道去哪 | 转盘随机，不用纠结 |
| 周末短途人群 | 想就近放松，不想花时间搜 | GPS 定位精准推荐周边 |
| 社恐但想组队的年轻人 | 不敢主动约人 | 广场浏览，低门槛加入 |
| 旅行小白 | 第一次出行不知道带什么 | AI 指南手把手教 |
| 懒得做攻略的人 | 不想花几小时查天气翻攻略 | 一键生成清单 |
| 大学生 / 年轻白领 | 预算有限、时间有限 | 高效决策 + 平摊费用 |

## 二、核心功能详述

### 1. 出发 — 场景化随机选城

不知道去哪？交给命运。

- **场景分类**：按心情选场景——沙漠 🏜、草原 🌿、海边 🏖、森林 🌲，选完进入对应城市池
- **转盘随机**：场景筛选后转动转盘，一键决定目的地，结果弹出庆祝动效
- **多维度过滤**：国内 / 国外 + 8 种旅行类型（文化、自然、美食、冒险、海滨、都市、历史、宗教）自由组合，与场景分类叠加使用
- **探索进度**：底部进度条记录你解锁了多少座城市，激励下一次出发
- **微信分享**：抽中城市后可直接分享给好友，标题自动带上城市名

### 2. 周边游 — 基于定位发现身边的美

不用远行，身边也有好风景。

- **GPS 定位**：App 启动时自动获取位置（GCJ-02 坐标系），支持手动刷新
- **周边城市**：800km 内城市按距离排序，卡片展示城市名、类型标签、距离（如 "328km"），一眼看到最近的远方
- **周边景点**：500km 内景点聚合展示，标注所属城市 + 距离，快速锁定感兴趣的目的地
- **一键导航**：点击城市卡片进入详情页，查看完整攻略、景点、美食
- **容错处理**：定位失败时显示重试按钮和状态提示，不阻塞使用

### 3. 搭子 — 找到志同道合的旅伴

一个人不敢出发？组队没那么难。

- **组队广场**：热门 / 最新 / 附近三个维度浏览队伍，卡片展示路线、时间、人数、标签
- **创建队伍**：出发地、目的地、队伍名、出发/返程时间、人数上限、是否需要审核、队伍介绍——信息齐全，拒绝无效沟通
- **申请加入**：看到心仪的队伍？写句话申请加入，等待队长通过
- **微信分享**：队伍详情页支持微信原生分享，分享标题自动拼装队伍名 + 路线，好友点击可直接进入队伍
- **关闭组队**：人齐了，创建者一键关闭，系统自动生成 AI 旅行指南

### 4. AI 旅行指南 — 出发前的最后一道保障

关闭组队后，AI 根据目的地、时间、人数自动生成个性化出行指南。

- **场景识别**：根据目的地城市标签自动匹配场景（沙漠/草原/海边/森林），无标签时按关键词智能推断
- **天气情况**：基于场景类型 + 出行季节，给出温度范围和穿衣建议（如沙漠"昼夜温差极大，白天炎热干燥，夜间寒冷"）
- **必带物品**：场景关键装备提醒——沙漠带防沙眼镜，海边带防水手机袋，森林带头灯
- **行李清单**：按衣物 / 电子产品 / 洗漱 / 药品 / 证件 / 其他 6 大类分组，标注"必带"项，可逐项勾选核对
- **出行贴士**：结合目的地特色 + 团队人数给出实用建议（如"建议租越野车""注意高原反应"等）

### 5. 我的 — 旅行数据一览

- **探索统计**：已探索城市数、收藏数、队伍数，一目了然
- **我的服务**：搭子管理（我创建 / 加入的队伍）、旅行规划（制定出行计划）、我的消息（队伍申请、审核通知）
- **更多入口**：收藏、历史记录、关于页统一入口

### 6. 城市详情 — 深度了解目的地

- **沉浸式头图**：视差滚动效果，城市封面大图
- **收藏 / 取消收藏**：一键收藏感兴趣的城市
- **景点列表**：核心景点名称 + 推荐理由
- **美食列表**：地道美食 + 简短介绍
- **旅行贴士**：目的地实用注意事项
- **预算参考**：按消费等级给出费用区间
- **微信分享**：分享标题自动拼装"我随机抽到了XX，一起去旅行吧！"

## 三、用户使用流程

### 流程 A：选择困难，随机出发

```
打开App → 出发Tab
  → 选择场景（沙漠/草原/海边/森林）
  → 可选：叠加 国内/国外 + 旅行类型 过滤
  → 点击转盘旋转
  → 随机结果弹出 + 庆祝动效
  → 查看城市详情（景点/美食/贴士/预算）
  → 收藏感兴趣的城市
  → 分享给微信好友
```

### 流程 B：周末短途，就近出行

```
打开App → 周边游Tab（自动定位）
  → 浏览周边城市（800km内，按距离排序）
  → 浏览周边景点（500km内，城市+距离标注）
  → 点击感兴趣的城市卡片
  → 进入城市详情了解攻略
  → 决定出发
```

### 流程 C：组队出行，找搭子

```
打开App → 搭子Tab
  → 浏览广场（热门/最新/附近）
  ┌─ 发现合适队伍 ─────────────────────────────┐
  │  点击队伍卡片 → 查看详情                      │
  │  → 写申请消息 → 申请加入                      │
  │  → 或：分享队伍给好友，邀请一起加入              │
  └──────────────────────────────────────────────┘
  ┌─ 没有合适队伍 ─────────────────────────────┐
  │  点击右下角"+" → 创建队伍                      │
  │  → 填写出发地/目的地/队伍名/时间/人数/审核设置  │
  │  → 发布后等待队员加入                          │
  │  → 分享队伍给好友，加速招募                      │
  └──────────────────────────────────────────────┘
```

### 流程 D：关闭组队，AI 生成指南

```
队伍人齐 → 创建者点击"关闭组队"
  → 确认关闭
  → AI 自动生成旅行指南（场景识别 + 季节判断 + 装备库匹配）
  → 队伍详情页显示"AI旅行指南已生成"横幅
  → 点击查看指南
    → 天气情况（温度范围 + 穿衣建议）
    → 必带物品（场景关键装备）
    → 行李清单（6大类，逐项勾选）
    → 出行贴士（目的地 + 人数定制建议）
  → 按清单逐项准备行李，安心出发
```

## 技术栈

- **框架**：UniApp + Vue 3 + TypeScript
- **状态管理**：Pinia (Composition API)
- **数据存储**：本地存储 (uni.setStorageSync)
- **定位**：uni.getLocation (GCJ-02 坐标系)
- **距离计算**：Haversine 公式
- **构建目标**：微信小程序 / H5

## 快速开始
